# Phase 3: UI/UX Design System & Prototyping

**Status**: Active
**Goal**: Establish a premium, modern design system for AgentsConfigHelper, prioritizing a developer-centric, cross-platform desktop experience.

## 1. Aesthetic Direction

- **Theme**: Dark theme optimized (with support for system matching, but defaulting to dark).
- **Vibe**: Sleek, modern, and professional—drawing inspiration from macOS System Settings, Cursor, and Google Cloud Console.
- **Typography**: Clean, highly legible sans-serif fonts (`Inter` via Google Fonts) for UI elements, paired with a modern monospaced font (`JetBrains Mono`) for diff viewers and raw config snippets.

## 2. Component Library Strategy

- **Base Framework**: Flutter Material 3, heavily customized with specific design tokens to avoid the generic "out-of-the-box" Android feel on desktop.
- **Tokens**: Sharp borders, subtle elevations, muted grays/blacks for backgrounds, and a high-contrast accent color (e.g., a vibrant blue or purple).

## 3. Core Layout Structure

- **Sidebar (Left)**:
  - Vertical list of discovered AI tools (Claude, Cursor, Devin, etc.).
  - Subtle hover states and a distinct active state indicator (e.g., colored left border or lighter background).
- **Main Content Area (Right)**:
  - **Header**: Tool name, icon, and status indicator.
  - **Body**: Sections for various settings (Rules, Permissions, Advanced).
  - **History/Backups View**: A dedicated tab or modal to view and restore previously saved configurations (utilizing the `.bak` files generated by `BackupService`).
  - **Controls**: Modern toggle switches, segmented buttons, and clean text fields for arrays.
- **Diff Viewer**:
  - Side-by-side or unified diff viewer showing what lines will change in the raw `.json`/`.yaml` files before saving.

## 4. Micro-Interactions & Feedback

- **Hover Effects**: Slight background color shifts for interactive elements.
- **Save Flow**: A floating action bar or fixed bottom bar that appears when unsaved changes exist, featuring a prominent "Review Changes" button.
- **Empty States**: Minimalist placeholder text/graphics when no agents are discovered.

## 5. Implementation Steps

1. Add `google_fonts` package.
2. Create `lib/theme/` directory with `app_colors.dart`, `app_text_styles.dart`, and `app_theme.dart`.
3. Apply the theme to `main.dart`.
4. Build a static scaffold of the layout (Sidebar + Main Area).
