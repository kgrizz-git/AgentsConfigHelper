# Research

This directory holds versioned raw discovery notes and initial path research.

- [`config-structured-editing-gap.md`](config-structured-editing-gap.md) records the
  gap between generic format parsing and schema-aware structured editing, with a staged
  direction for closing it.

Raw dated research here supports the catalog. It is the input material, not the
reviewed reference: sources are captured as-of a point in time and may predate current
vendor docs.

[docs/supported-tools.md](../../docs/supported-tools.md) is the **reviewed curated
reference** for supported AI agent and IDE configs. Its evidence table records which
tools have been substantively reviewed against current vendor sources, which primary
source supports each, and whether a token-free repository fixture exists.
